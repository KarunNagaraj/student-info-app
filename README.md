# student-info-app

1) Project Title - Student-info-app

2) Team Members - Ekta Singh, Karun Nagaraj, Rahul Mohan Gupta

3) Project Description - Simple student info app that has a form which takes Name, ID and email.

4) Technologies Used - HTML,CSS and JAVASCRIPT

5) Git Branching Strategy - Various branches were created based on functionality such as javascript, changing app title, css etc. 

6) Pull Requests Created

7) Merge Conflict:
    A merge conflict was created when the feature/app-title branch changed the h1 tag and committed, a pull request was created and the branch was merged into main. 
    Then another branch feature/javascript modified the h1 tag locally to something else and comitted and pushed, a pull request was created. The PR immediately showed a merge conflict that had to be resolved. 
    It was resolved by manually accepting the incoming change and rejecting the current change. 

8) How to Run the Application - The application can be run by opening index.html in any browser.
